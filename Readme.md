ATM Interface 💳

Project 3 – Java Programming

A simple ATM Interface created using Java. The program allows the user to check balance, deposit money, withdraw money, and exit the ATM.

Features

- Check balance
- Deposit money
- Withdraw money
- Check insufficient balance
- Validate user input
- Exit the ATM

Concepts Used

- Java
- Classes and methods
- "if-else"
- "switch"
- "do-while" loop
- "Scanner"
- Input validation
