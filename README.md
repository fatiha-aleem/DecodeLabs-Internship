#decodelabs-Project1
Number Guessing Game

About the Project

This is a simple Java console-based Number Guessing Game. The computer randomly chooses a number between 1 and 100, and the player gets 5 attempts to guess it correctly.

This game also keeps track of the score and gives the player the option to play multiple rounds.

Features:

- Randomly generates a number between 1 and 100.
- Gives 5 attempts in each round.
- Gives hints when the guess is too high or too low.
- Handles invalid input.
- Calculates points based on the number of attempts used.
- Keeps track of the total score.
- Allows the player to play multiple. rounds

Technologies Used:

- Java
- Scanner
- Random
- InputMismatchException

What I Learned:

This project helped me practice loops, conditional statements, user input, random numbers, exception handling, and score management in Java.
